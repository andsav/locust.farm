# Roles and permissions plan: removals and checks

Status: companion to the proposed
[roles and permissions implementation plan](roles-and-permissions-plan.md) of
2026-10-05. Not accepted and nothing here is built.

For each phase this lists what it removes or rewrites and, in a table, the
behaviours it must show with the test or command that shows each. The lists
were written with the first draft of each phase and amended when the phases
were reconciled. Where a list and the plan disagree, the plan is right. Paths
were read in the source at `cfb5b45`; a test named here that does not exist
yet is one the phase adds. K1, named in some rows, is the phase of the
[host safety and ending plan](host-safety-and-ending-plan.md) that gives a
goal's governance its own key. It lands directly before Phase 4.
