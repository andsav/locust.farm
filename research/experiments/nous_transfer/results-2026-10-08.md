## Results

Ten historical questions, ten agents, three profile conditions and three stages
produce 900 calls. Brier scores below weight the two event clusters equally,
then questions equally within each cluster. **Lower is better.**

| Profile | Initial | Private recheck | Peer exchange |
| --- | --- | --- | --- |
| Neutral | 0.226247 | 0.242148 | 0.260864 |
| Published Nous | 0.191390 | 0.247347 | 0.231634 |
| Structured proxies | 0.223550 | 0.237562 | 0.235047 |

Published profiles lowered initial ensemble Brier by **0.034857** relative to
neutral prompts. Structured proxies lowered it by **0.002697**. These are observed
historical differences, not established general forecasting improvements.
The published-profile advantage comes from the single question in the second
cluster: Brier 0.266256 versus neutral 0.336400. On the nine Eurovision questions,
published profiles are slightly worse: 0.116523 versus 0.116094.

Both revision methods increased loss relative to the initial forecasts in every
profile condition. Compared specifically with private rechecking, peer exchange
lowered loss for published and structured profiles but increased it for neutral
prompts. Thus the negative profile/communication interaction does not mean that
exchange improved on the initial profile forecasts.

One completed structured exchange response used string-valued peer IDs where
integers were required. It was retained as invalid and scored with the declared
0.5 fallback. All other 899 responses passed the output rules. There are no
missing calls. All groups have ten fully valid questions except structured
exchange, which has nine. No schema-invalid response was retried or replaced.

## Interpretation limits

- The ten questions comprise nine related Eurovision questions and one question
  from a second event/date cluster. The single-question cluster carries half the
  aggregate Brier weight. Two clusters cannot establish a reliable effect;
  confidence intervals remain suppressed.
- All cases are historical. Possible outcome memory and residual brief leakage
  remain unresolved. This is not prospective forecasting evidence.
- All ten questions now have all initial calls available. Equal byte padding
  produced **9.37–11.29%** token imbalance, above the stated 5% target. Published
  profiles average 238.5 more input tokens than neutral; structured profiles
  average 135.9 more. This is not a fully length-controlled comparison.
- The structured arm changes content as well as encoding. It cannot isolate a
  repair to the original unreleased translator.
- Recovery was requested after seeing partial outputs. It changes the transport
  attempt policy, not the prompts or cohort, but the amendment is not a
  preregistered part of the original run. It preserves the first completed answer
  and does not select answers based on their scores.

The completed run is useful evidence about these particular prompts and cases.
It does not establish that Nous profiles improve general forecasting or that
communication improves the initial forecasts.

## Verification

The first run exposed a verifier bug: the transport hashes compact JSON while
its verifier expected spaced JSON. The verifier was corrected without changing
frozen inputs or model outputs. The recovered run was verified using the actual
transport hash function.

- All **900 selected requests and 903 attempt hashes** verified against the
  frozen inputs reconstructed from pinned upstream artifacts.
- Every original attempt and completed response was preserved; baseline-evidence
  and recovery-code hashes were independently checked.
- Scores, diagnostics, first-completed-answer selection, all-attempt accounting
  and retry request identity were recomputed successfully.
- **22 Python tests passed**, including real-transport hashing with mocked HTTP,
  retry recovery, reservation accounting, answer retention and tamper rejection.
- Documentation/index/link checks passed. No Rust code changed.

Recompute the saved evidence from the repository root using Python 3.9.7, the
runtime used to export these exact floating point summaries:

```sh
python3 research/experiments/nous_transfer/evidence.py verify research/experiments/nous_transfer/completed-evidence-2026-10-08.json --upstream output/nous-paper-review-2026-10-07
```

This makes no model API calls. It checks reconstruction against local hashes,
not a provider-signed attestation of requests or responses. The original run
folder remains unchanged; continuation artifacts are in ignored
`output/nous-transfer-completed-2026-10-08/`.

The separate replay cohort, behavioral-direction probes and prospective cohort
remain unrun. They are not needed to finish these 900 calls, which are complete.
